# Online Library Management System

## Project Description

Many local libraries still rely on outdated paper-based tracking systems, requiring cash payments and manual record-keeping. This lack of automation creates several challenges:
* Inability to check book inventory in real-time.
* Difficulty tracking borrowing periods and identifying overdue books.
* Limited payment options for users.

**Solution:**  
This project is an online management system for book borrowings designed to automate library operations, streamline tracking for administrators, and improve the user experience.

The system provides a fully functional REST API (browsable interface) to handle book inventory, borrowings, user management, and payment tracking.
